# AI Data Analysis Report Skills

## Purpose

Analyze raw datasets, identify meaningful insights, and generate accurate, comprehensive, data-driven analytical reports.

## Core Skills

| Skill | Core Capabilities |
|---|---|
| **1. Data Extraction** | Extract structured data from Excel, CSV, PDF, JSON, and databases. |
| **2. Data Cleaning** | Identify missing values, duplicates, inconsistencies, outliers, and formatting errors. |
| **3. Data Validation** | Verify data accuracy, consistency, completeness, and calculation integrity. |
| **4. Exploratory Data Analysis (EDA)** | Examine distributions, patterns, correlations, anomalies, and relationships between variables. |
| **5. Statistical Analysis** | Calculate descriptive statistics, growth rates, variance, correlations, and statistical significance. |
| **6. KPI Analysis** | Evaluate performance indicators, targets, benchmarks, and actual-versus-planned results. |
| **7. Trend Analysis** | Analyze historical performance, growth patterns, seasonality, and changes over time. |
| **8. Comparative Analysis** | Perform YoY, MoM, QoQ, segment, category, and benchmark comparisons. |
| **9. Root Cause Analysis** | Investigate performance gaps, identify contributing factors, and evaluate causal hypotheses. |
| **10. Predictive Analysis** | Develop forecasts, scenarios, trend projections, and sensitivity analyses. |
| **11. Data Visualization** | Generate line charts, bar charts, waterfall charts, heatmaps, scatterplots, and analytical dashboards. |
| **12. Insight Generation** | Translate quantitative findings into meaningful, evidence-based analytical conclusions. |
| **13. Report Structuring** | Organize findings into executive summaries, methodologies, detailed analyses, conclusions, and appendices. |
| **14. Automated Report Generation** | Produce formatted analytical reports in Word, PDF, Excel, HTML, and PowerPoint. |
| **15. Quality Assurance** | Validate calculations, reconcile reported figures with source data, document assumptions, and prevent unsupported claims. |

## Standard AI Data Analysis Report Structure

1. **Executive Summary** — Main findings and critical insights.
2. **Analysis Objectives** — Scope, questions, and analytical goals.
3. **Data Overview** — Sources, coverage, quality, and limitations.
4. **Methodology** — Analytical techniques, formulas, and assumptions.
5. **Descriptive Analysis** — Statistical summaries and data distributions.
6. **Trend & Comparative Analysis** — Historical changes and performance differences.
7. **Key Drivers & Root Causes** — Factors contributing to observed outcomes.
8. **Predictive & Scenario Analysis** — Forecasts, uncertainties, and sensitivities.
9. **Data Visualizations** — Charts and supporting analytical tables.
10. **Key Findings & Insights** — Evidence-based interpretations.
11. **Conclusions & Recommendations** — Prioritized actions supported by the analysis.
12. **Appendix** — Detailed calculations, data definitions, and supporting information.

## Core Skill Definition

Transform complex raw data into accurate, structured, visually compelling, and actionable analytical reports through automated data processing, statistical analysis, trend identification, insight generation, and professional report production.
